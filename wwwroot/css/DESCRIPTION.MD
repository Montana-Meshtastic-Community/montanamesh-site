# Website CSS

This folder contains site-wide CSS for the MontanaMesh website.

## Current Role

`site.css` controls the industrial signal-operations visual theme, design tokens, local WebP hero backgrounds, abstract page map-grid texture, homepage Rimrocks signal-sweep hero background, live telemetry panel, route rail, service cards, navigation styling, responsive behavior, reveal animations, focus states, and light/dark presentation used by the shared layout and public pages.

## Documentation

Whenever styling, layout behavior, responsive rules, or theme behavior changes in this folder, keep this service-local note current in the same change.
