# Website Images

This folder contains image assets used by the MontanaMesh website, including the logo, favicon image, and local page backgrounds.

## Contents

- `logo.png`: navbar and manifest-adjacent logo.
- `logo.svg`: original vector logo source used when regenerating raster logo assets.
- `favicon.png`: PNG favicon used by the shared layout.
- `originals/`: untouched source logo files used to regenerate the served raster and vector assets.
- `backgrounds/`: optimized local WebP page backgrounds referenced by `wwwroot/css/site.css`.

## Documentation

Whenever image assets are added, removed, renamed, optimized, or replaced in this folder, keep this service-local note current in the same change.
